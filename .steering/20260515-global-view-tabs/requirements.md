# グローバルビュー タブ切り替え実装 — 要求内容

## 概要

グローバルビューのツールバー右側にタブ切り替えを追加する。
ツールバー下の全エリアがタブで切り替わるレイアウトを実現する。

## タブ構成（4タブ）

### 1. ビュー表示（デフォルト）
- 現在の表示状態そのもの（左パネル + 3Dシーン + タイムライン）

### 2. 工場情報
- 工場に関連する情報を表示・編集するコンフィグ画面
- 左サイドバー: 情報のグルーピング項目名（基本情報, ステーション一覧, 接続一覧, メタデータ）
- 右の大きな表示部: 選択グループに対応する詳細フィールド
- JSONのインポート・エクスポート機能

### 3. 3Dモデル編集
- グローバルビューにおける表示設定を行う画面
- 左サイドバー: 表示項目のグルーピング（グローバル設定, 設備シェル, ステーション, カラー設定）
- サイドバー項目クリック → フローティングウィンドウが表示
- フローティングウィンドウ内の選択は即座に3Dに反映
- フローティングウィンドウに確定ボタン（押すと保存してウィンドウを閉じる）
- 右側: 3Dビュー（既存シーンと共有）

### 4. ロジック編集
- グローバルビューのロジック編集（設備間の接続を接続線で繋げる）
- scenario editorのようなイメージ
- 左サイドバー: 設備モデル一覧 + 新規設備ボタン
- 新規設備追加 → 立方体として配置モード
- 設備をダブルクリック → ローカルビュー（local-window）に遷移
- 中央: SVGキャンバス（ドラッグ移動, 接続線描画）

## レイアウト要件

- ツールバーの右端にタブボタンを配置（ローカルビューの tab-bar と同様のスタイル）
- ツールバーより下のエリア全体がタブで切り替わる
- タブは `#app` の flex column の中でツールバー直下に配置
