# 要求仕様書

## 機能1: 設備モデル編集画面の位置編集

### 背景
ローカルウィンドウ（`local-window.html`）の「ロジック編集」タブは現状 SVG が存在するが JS が全く動いていない（`#logic-canvas` 等の存在しない DOM を参照している）。

### 要求
- ロジック編集タブで内部ステーションを SVG キャンバスにドラッグ配置できること
- 左サイドバーに位置編集用ツール（選択/移動ツール）を配置すること
- 右プロパティパネルに positionX / positionY の表示・編集フィールドを追加すること
- 「保存して閉じる」で内部ステーションの positionX/Y が保存されること

### 非機能要求
- 既存の接続追加・削除・ステーション追加・削除機能も動作すること
- 内部ステーションが0件の場合は空のキャンバスを表示（追加操作可能）

## 機能2: グローバルビューの上面視（直交投影）

### 背景
「上面視」ボタンは現在、透視投影カメラを真上から見る角度に動かすだけ。左クリックでパンしたときに3D回転がかかり作業しにくい。

### 要求
- 上面視ボタンを押したとき、直交投影カメラ（OrthographicCamera）に切り替えること
- 直交投影時はマウス左ドラッグでパン（回転なし）になること
- 再度ボタンを押す（または同等の操作で）透視投影に戻れること
- 直交投影時もクリックによる設備・マシン選択が正常に動作すること
