# factory-visualizer 要求定義

## 概要

factory-simulation リポジトリ内に `factory-visualizer/` という新サービスを作成する。
既存の **sim-visualizer + sim-editor を統合・作り直し** たデジタルツインダッシュボード。

**背景:** 既存サービスの座標系バグが多かったため、クリーンに再設計する。

---

## サービス情報

- サービス名: `factory-visualizer`
- アクセスURL: `https://localhost/factory-visualizer/`
- 技術: nginx:alpine + HTML/CSS/Vanilla JS + Three.js 0.160.0
- docker-compose.yml + nginx-proxy/nginx.conf も更新

### サービス構成変更（今回の作業全体）

| サービス | 変更 |
|---------|------|
| `factory-visualizer` (新) | **新設** — sim-visualizer + sim-editor + sim-executor UI の統合後継 |
| `sim-visualizer` (8081) | **廃止** — factory-visualizer に統合 |
| `sim-editor` (8082) | **廃止** — factory-visualizer に統合 |
| `sim-executor` (8083) | **廃止** — factory-visualizer に統合 |
| `sim-executor-backend` (8084) | **廃止** — SimDB ロジックを realtime-gateway に統合 |
| `realtime-gateway` (8090) | **拡張** — SimDB クエリ・実行管理を吸収 |
| `simulation-core` (8080) | **変更** — scenarioId → factoryId 対応、factory_stations を直接読む |
| `sim-portal` (8085) | **更新** — 廃止サービスのリンク削除、factory-visualizer 追加 |

## ステーションタイプ概念モデル（重要・今回の壁打ちで確定）

### 今回スコープ内: Machine

| 項目 | 内容 |
|------|------|
| `station_type` | `"machine"`（旧 `"moduler"` から改名） |
| 意味 | 物理的な1台の設備・機械 |
| 3Dモデル | あり（voxel grid / GLTF/GLB / 円柱フォールバック） |
| 内部ステーション | あり（processing / source / drain 等を子として持つ） |
| グローバル表示 | Machine の 3D モデルをそのまま表示 |

### 将来スコープ（概念定義のみ、今回は実装しない）: Moduler

| 項目 | 内容 |
|------|------|
| `station_type` | `"moduler"` |
| 意味 | 複数 Machine の論理グルーピング（ライン・工程等） |
| 3Dモデル | **なし**。内包する Machine 群の 3D モデルがそのまま Moduler の外観になる |
| 内包要素 | Machine、または入れ子 Moduler（再帰ネスト可） |
| 所属ルール | Machine は必ず何らかの Moduler に所属する |
| グローバル表示（移動中のみ） | 点線のバウンディングボックスを表示。配置確定後は消える |
| 内部ステーション表示 | ON/OFF トグルで切替（全 Machine の内部ステーションを一括制御） |

### Moduler 表示の動作イメージ

```
通常時:
  [Machine A の 3Dモデル] [Machine B の 3Dモデル]  ← Moduler境界は非表示

ドラッグ移動中:
  ┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┐
  ╎ [Machine A] [Machine B] ╎  ← 点線ボックス出現
  └─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┘

配置確定後:
  [Machine A の 3Dモデル] [Machine B の 3Dモデル]  ← 点線消える
```

### Entry / Exit

- **エイリアス（飾り）** として扱う。機能的な意味なし

## 画面構成

### グローバル表示部（通常の3Dビュー）

工場全体を俯瞰する3Dビュー。モジュラーステーション（設備）群を表示。

### ローカル表示部（設備ダブルクリックで別ウィンドウ）

1設備ごとの詳細ビュー。複数同時表示可能。  
ツールリボン直下に**編集モード切替タブ**を配置:

| タブ | 内容 |
|------|------|
| モデル情報編集 | 設備名・メタ情報の設定 |
| 3Dモデル編集 | 格子ボクセル or glTF/GLB インポート、原点(0点)設定 |
| ロジック編集 | 上面視でステーション配置（平たい円柱）・接続線設定 |

保存して閉じる → グローバルに反映。

## 各UIコンポーネント詳細

### メニューバー
- Windowsスタイル（ブラウザ最上部）
- メニュー: ファイル / 編集 / 選択 / 表示 / 移動
- まずはメニューバーとボタンがあるだけのブランク実装

### ツールリボン
- メニューバー直下、Office（PowerPoint/Word/Excel）風
- まずはブランク実装

### 左パネル（オブジェクト一覧）
- 設備・ステーション・ワークの一覧表示
- フィルタボタン（種類でフィルタ）
- ソートボタン

### カメラパネル
- 3D空間内に**吹き出し型オブジェクト**として配置
- 3Dオブジェクトのパネルに映像が表示（工場カメラの位置に配置予定）
- 今回はUIプレースホルダーのみ

### AIエージェントパネル
- 右下フローティング（初期位置）
- 表示ON/OFFを設定可能
- クイックアクションボタン5つ + テキスト入力（UIのみ）
- ドラッグ移動可能

### タイムライン（タイムマシン）
- 過去（実績）: 塗りつぶしドット●
- 現在: グリーンドット●（強調）
- 未来（シミュレーション）: 空ドット○
- 再生コントロール: ⏮ ⏸/▶ ⏭、速度 0.5x/1x/2x/5x/10x
- 時刻表示: 絶対時刻形式（例: 2025/05/24 10:33:47）

### フローティング情報パネル
- オブジェクトクリックで追加表示（複数同時表示可、モーダル的）
- 次のオブジェクトをクリック → さらにもう1枚追加
- **設備パネル表示項目（暫定）:**
  - 設備名、ステータス
  - 設備に入ってからの経過時間
  - 搬出可なのに後工程が搬入可にならず止まっている時間
  - その他（別途追加）
- **ワークパネル表示項目（暫定）:**
  - ワークID、現在位置
  - その他（別途追加）

## 3D表示仕様（確定）

### 設備モデルの表示優先順位（グローバル表示部）

1. `model3DGrid` あり → ボクセルグリッドシェル表示
2. `model3DGltf` / `model3DGlb` あり → GLTF/GLB モデル表示
3. どちらもなし → 円柱フォールバック

### 内部ステーション（モジュラー内部）

- 平たい円柱で表示（既存 sim-visualizer と同様）
- 左パネルの「表示設定」セクションで制御

### ワーク表示

- 赤いスフィア（既存 sim-visualizer と同様）

### リアルタイム更新

- WebSocket ベースのリアルタイム更新を引き継ぐ（ワーク位置 + インターロック状態）

### シーンテーマ（背景・床色）

3種類を左パネルから選択可能:

| オプション | 説明 |
|-----------|------|
| テーマに合わせる | `prefers-color-scheme` に連動（auto） |
| ライト | 明るい固定テーマ（白〜薄グレー系） |
| ダークネイビー | ダークネイビー固定（`#0f1629` 系） |

- **テーマに合わせる** 時: dark → ダークネイビー設定、light → ライト設定を自動適用
- 床グリッドも引き続き表示（テーマに応じて色変更）

### 左パネル「表示設定」セクション

```
表示設定
├── シーンテーマ       [テーマに合わせる / ライト / ダークネイビー]
├── 設備シェル透明度   [0.1 ────●──── 1.0]
├── 内部ステーション径 [5 ──●──────── 30]
├── 内部表示           [ON/OFF]
├── ステーション名表示  [ON/OFF]
├── ワーク表示         [ON/OFF]
└── インターロック表示  [ON/OFF]
```
