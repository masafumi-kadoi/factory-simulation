# 要求内容

## 概要

Machine Editorのロジック編集タブを刷新し、設備のGLTF 3Dモデルを上面投影した画像の上にステーションを配置できるようにする。配置した座標は設備モデル原点からの相対座標（Three.js単位）としてSimDBに保存する。

## 背景

現状のロジックエディタはSVGキャンバス上でステーションをピクセル座標で管理しており、実際の設備レイアウトとの対応が取れていない。GLTFモデルの上面投影を背景に使うことで、ステーションの物理的な配置位置を正確に把握・編集できるようにする。

また、現状の子ステーション座標はSVGピクセル座標で保存されているが、設備モデル原点からの相対座標（Three.js単位）に変更する。グローバル座標はシミュレーション実行時に `machine.positionX + station.positionX` で演算する。

## 実装対象の機能

### 1. GLTF上面投影バックグラウンド
- `model3DGlb` が存在する場合、Three.js OrthographicCameraで上面（-Y方向）からGLTFモデルをレンダリング
- レンダリング結果をcanvasに表示し、SVGの後ろ側に配置
- `model3DGlb` がない場合は従来のSVGグリッド背景のまま

### 2. 左サイドバー: 未配置ステーション一覧
- 現在の「追加ボタン（Source/処理/Drain等）」を廃止し、DBに登録済みの子ステーション一覧を表示
- 未配置（positionX = null）のステーションのみリスト表示
- 各アイテムはドラッグ可能
- 「新規追加」ボタンでステーション種別を選択して追加（DB登録＋未配置リストに追加）

### 3. ドラッグ＆ドロップ配置
- 左サイドバーからドラッグしてキャンバス上にドロップ
- ドロップ位置をGLTFモデルのローカル座標（X, Z）に変換
- 配置済みになったステーションはサイドバーから消え、SVG上にノードとして表示
- 既存の「ドラッグで移動」は維持（配置済みノードをSVG上でドラッグ移動）

### 4. 相対座標でのSimDB保存
- 子ステーションの `positionX` = ローカルX座標（Three.js単位、設備原点基準）
- 子ステーションの `positionY` = ローカルZ座標（Three.js単位、設備原点基準）
- 未配置は `positionX = null, positionY = null`

## 受け入れ条件

### GLTF投影
- [ ] model3DGlbがある設備でロジックタブを開くとGLTF上面投影が表示される
- [ ] 投影は設備モデルの全体が収まるようにスケールされる
- [ ] model3DGlbがない場合は従来のSVGグリッドが表示される

### サイドバー
- [ ] 未配置の子ステーションが左サイドバーに一覧表示される
- [ ] 配置済みの子ステーションはサイドバーから消え、キャンバス上に表示される
- [ ] 新規追加ボタンでステーションを追加できる

### ドラッグ＆ドロップ
- [ ] サイドバーからドラッグしてキャンバス上にドロップできる
- [ ] ドロップ位置がGLTFローカル座標に変換されてpositionX/Yにセットされる
- [ ] 配置後はサイドバーから消えてSVG上に表示される

### 保存
- [ ] 「保存して閉じる」で相対座標がSimDBに保存される
- [ ] 未配置ステーションはpositionX/Y = nullで保存される

## スコープ外

- グローバルビューでの子ステーション3D表示（今回は配置UIのみ）
- ステーション間接続の表示ロジック変更（既存のまま）
- サブユニット（第3階層）への対応
