# 要求内容

## 概要

工場の「過去の実績データ（リアルタイムポーリング）」・「現在時刻」・「シミュレーション予測結果」を1つの48時間タイムラインに統合し、工場選択直後から稼働状況と予測を直感的に確認できるようにする。

## 背景

現状のタイムラインはシミュレーション実行結果のみを表示する単純なスライダーであり、以下の問題がある：

1. **リアルタイムデータ未統合**: 外部工場DBからの稼働実績がタイムラインに反映されない
2. **source_type バグ**: 工場ベースのシミュレーション実行が `source_type='realtime'` で保存されてしまっている（正しくは `'simulation'`）
3. **シミュレーション起動の柔軟性不足**: 任意の日時からシミュレーションを開始できない。スケジュール実行もできない

## 実装対象の機能

### 1. source_type バグ修正
- 工場ベースのシミュレーション実行で `CreateRealtimeDataSource` を誤って呼び出している箇所を `CreateDataSource("simulation", ...)` に修正する

### 2. factory-poller サービス
- 外部工場DBを1秒間隔でポーリングし、新規 `item_movement` イベントを内部DBへ投入する新規Goサービス
- realtime-gateway の API 経由でポーリングの開始・停止を制御できる
- 工場が選択されたとき、フロントエンドからポーリング開始を要求する
- ポーリング中のデータは `source_type='realtime'` のデータソースとして蓄積される

### 3. 3ゾーンタイムライン（フロントエンド）
- **左ゾーン（過去24時間）**: 選択工場のリアルタイムデータソースのイベントを表示
- **中央マーカー**: `Date.now()` の位置を常時表示（リアルタイムデータが存在する場合のみ）
- **右ゾーン（未来24時間）**: シミュレーション実行結果のイベントを表示
- タイムライン幅は固定48時間（左24h + 右24h）、中央が現在時刻
- 左右いずれの領域もシーク可能で、位置に応じたデータソースのイベントを `applyHistoryAtTime` に渡す

### 4. シミュレーションスケジューリングUI
- 任意の日時（過去・未来問わず）を開始日時として指定してシミュレーションを実行できる
- スケジュール実行UI（Windows タスクスケジューラ的なイメージ）: 実行日時・間隔などを設定
- 過去の実行結果一覧から選択してタイムラインに表示できる
- 現在の「実行する」ボタンを廃止し、スケジューリングパネルに統合する

## 受け入れ条件

### source_type バグ修正
- [ ] 工場を選択してシミュレーションを実行すると、`data_sources` テーブルに `source_type='simulation'` で保存される
- [ ] 既存の `source_type='realtime'` を持つシミュレーション実行データは削除済み（既対応）

### factory-poller サービス
- [ ] `POST /api/factories/{id}/poller/start` を呼ぶとポーリングが開始される
- [ ] `POST /api/factories/{id}/poller/stop` を呼ぶとポーリングが停止し、`data_source.ended_at` が設定される
- [ ] `GET /api/factories/{id}/poller/status` でポーリング中か否かと active な data_source_id を取得できる
- [ ] ポーリングで取得したイベントが内部DBの `item_movement` に挿入され、WebSocketで配信される
- [ ] 外部工場DBへの接続情報は `factories` テーブルの `factory_db_*` カラムから取得する

### 3ゾーンタイムライン
- [ ] タイムラインが常時48時間幅（中央 = Date.now()）で表示される
- [ ] 左ゾーン（青系）・現在マーカー（緑）・右ゾーン（橙系）が視覚的に区別される
- [ ] 左ゾーンのシークでリアルタイムデータソースのワーク位置が再現される
- [ ] 右ゾーンのシークでシミュレーション結果のワーク位置が再現される
- [ ] 工場選択直後にポーリングが自動開始し、左ゾーンにデータが表示される

### シミュレーションスケジューリングUI
- [ ] 任意の日時を開始日時として指定してシミュレーションを即時実行できる
- [ ] スケジュール設定パネルで実行設定を保存・削除できる
- [ ] 過去の実行結果リストをクリックすると、そのシミュレーション結果がタイムラインの右ゾーンに表示される

## 成功指標

- 工場を選択してから10秒以内に過去24時間の稼働データがタイムラインに表示される
- リアルタイムイベントがポーリング取得後、1秒以内にタイムラインに反映される（WebSocket経由）
- シミュレーション結果を右ゾーンで再生したとき、左ゾーンの稼働実績と連続して見える

## スコープ外

以下はこのフェーズでは実装しません：

- 複数のリアルタイムデータソースの同時表示（工場あたり最新1件のみ）
- シミュレーション結果の自動スケジュール実行（設定UIは作るが実際のcron実行は対象外）
- ポーリングデータの品質チェック・異常検知
- 外部工場DBのスキーマが内部DBと異なる場合の変換ロジック
