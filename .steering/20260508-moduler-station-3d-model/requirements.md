# 要求内容

## 概要

ModularStation の内部編集画面に「モデル編集モード」を追加し、格子状グリッドを使ってステーションの3Dモデル形状を定義できるようにする。モデルの編集状態は独自グリッド形式（`model3DGrid`）で保存され、Visualizerで3D表示される。外部 glTF モデルのインポートにも対応し、エクスポートはグリッドモデル・インポートモデル問わず glTF ファイルとしてダウンロードできる。

## 背景

現状、Visualizerでは ModularStation は単純な円柱として表示される。実際の工場設備のレイアウト検討に使うためには、ステーションの外形（形状・サイズ）を視覚的に定義・表示できる機能が必要。  
外部ツール（Blender等）で作成したモデルを使いたいニーズにも対応するため glTF インポートをサポートするが、編集操作の整合性を保つため**グリッドと glTF インポートは排他的な関係**とする。

## モデルデータの種類と関係

```
グリッドエディタで作成
  → model3DGrid { gridSize, height, cols, rows, cells }
     └─ Visualizer: BoxGeometry で描画
     └─ エクスポート時のみ GLTFExporter で glTF 生成してダウンロード（保存はしない）

外部 glTF をインポート
  → model3DGltf { /* glTF 2.0 JSON */ }  ← .gltf の場合
     model3DGlb  "<base64>"               ← .glb の場合
     └─ Visualizer: GLTFLoader で描画
     └─ エクスポート: 保存済みデータをそのままダウンロード

※ model3DGrid と model3DGltf/model3DGlb は同時には存在しない（排他的）
```

## 実装対象の機能

### 1. 内部編集画面のモード切替

- ModularStation をダブルクリックして入る内部編集画面に、上部ツールバーを追加
- ツールバーに「ロジック編集」「モデル編集」の2つのモード切替ボタンを配置

### 2. モデル編集モード（グリッドエディタ）

- **ブロックサイズ切替ボタン**: 格子サイズ・列数・行数を入力するモーダル。確定でグリッドを再描画
- **ブロック高さ切替ボタン**: ブロックの高さを入力するモーダル
- **セルクリック**: 格子セルを選択/解除（シアン色ハイライト）
- **クリックドラッグ**: ドラッグ経路のセルを順に選択
- **モデル決定ボタン**: `{ gridSize, height, cols, rows, cells }` を `station.config.model3DGrid` に保存
- **インポートボタン**: .gltf / .glb ファイルを選択するダイアログを開く。インポート後は「外部モデル設定済み」状態に切り替わり、グリッド選択は無効化される
- **リセットボタン**（外部モデル設定済み時のみ表示）: 外部モデルを破棄してグリッド編集状態に戻す
- **エクスポートボタン**: モデル設定済みの場合に有効
  - `model3DGrid` が存在する場合: GLTFExporter で glTF を生成してダウンロード（`model.gltf`）
  - `model3DGltf`/`model3DGlb` が存在する場合: 保存済みデータをそのままダウンロード

### 3. glTF インポート

- ファイル選択ダイアログで `.gltf`（JSONテキスト）または `.glb`（バイナリ）を選択
- `.gltf`: JSON.parse → `config.model3DGltf` に保存、`config.model3DGrid` を削除
- `.glb`: Base64 エンコード → `config.model3DGlb` に保存、`config.model3DGrid` を削除
- インポート後: グリッドエディタが「外部モデル設定済み」状態になり、セル選択は不可
- 無効なファイルはインライン通知でエラー表示（既存モデルは変更しない）

### 4. ロジック編集モードでのモデルフットプリント表示

- `model3DGrid` が存在する場合: cells の2Dフットプリントを半透明で SVG キャンバスの背後に表示
- `model3DGltf`/`model3DGlb` が存在する場合: 「📦 外部モデル設定済み」テキストを表示
- フットプリントはインタラクションを妨げない（pointer-events: none）

### 5. Visualizerでのカスタム3Dモデル表示

- `model3DGrid` が存在する場合: `cells` の各セルを `BoxGeometry` で描画
- `model3DGltf`/`model3DGlb` が存在する場合: `THREE.GLTFLoader` でロードして表示
- どちらも存在しない場合: 従来の円柱表示

## 受け入れ条件

### モード切替
- [ ] ModularStation をダブルクリックするとモード切替ツールバーが表示される
- [ ] 現在のモードがアクティブ状態で強調表示される

### グリッドエディタ
- [ ] ブロックサイズ切替・ブロック高さ切替モーダルが正しく動作する
- [ ] セルのクリック選択・ドラッグ選択が動作する
- [ ] 「モデル決定」を押すと `config.model3DGrid` に保存される
- [ ] 保存後 `GET /api/scenarios/{id}` のレスポンスに `model3DGrid` フィールドが含まれる
- [ ] 再度モデル編集モードを開くと、前回のグリッド状態（セル・サイズ）が復元される

### インポート
- [ ] 「インポート」ボタンでファイル選択ダイアログが開く
- [ ] `.gltf` インポートで `config.model3DGltf` に保存され、`model3DGrid` が削除される
- [ ] `.glb` インポートで `config.model3DGlb` に保存され、`model3DGrid` が削除される
- [ ] インポート後にグリッドエディタが「外部モデル設定済み」状態になる
- [ ] 「リセット」ボタンで外部モデルが削除されグリッド編集状態に戻る
- [ ] 無効なファイルでエラーメッセージが表示され既存モデルは変更されない

### エクスポート
- [ ] `model3DGrid` の場合: `model.gltf` ファイルがダウンロードされる（GLTFExporter で生成）
- [ ] `model3DGltf` の場合: `model.gltf` がダウンロードされる
- [ ] `model3DGlb` の場合: `model.glb` がダウンロードされる
- [ ] モデル未設定時はエクスポートボタンがグレーアウトしている

### ロジック編集でのフットプリント
- [ ] `model3DGrid` 設定済みの場合、フットプリントが半透明表示される
- [ ] フットプリント上でステーション配置のインタラクションが妨げられない

### Visualizer表示
- [ ] `model3DGrid` 設定済みの ModularStation が BoxGeometry でカスタム形状表示される
- [ ] `model3DGltf`/`model3DGlb` 設定済みの ModularStation が GLTFLoader で表示される
- [ ] どちらも未設定の場合は従来の円柱表示

## エッジケース

| ケース | 期待する動作 |
|---|---|
| セル未選択で「モデル決定」 | 「セルを選択してください」メッセージを表示。保存しない |
| ブロックサイズ縮小で選択セルが範囲外になる | 範囲外のセルを除去してからグリッドを再描画 |
| 「モデル決定」を押さずに「ロジック編集」へ切替 | 未確定の選択は破棄。フットプリントは直前に保存済みのモデルを表示 |
| drillUp でモデル編集モードのまま移動 | ツールバーを非表示にし、未確定の選択を破棄 |
| `model3DGrid` と `model3DGltf` が両方存在する | 発生しないよう設計するが、万一の場合は `model3DGrid` を優先表示 |
| 外部モデル設定済み状態でグリッドのセルをクリック | 操作を無視（グリッドは非インタラクティブ状態） |
| インポート後に「モデル決定」ボタンを押す | ボタンはグレーアウト（外部モデル設定済み中は無効）。「リセット」でグリッドに戻ってから操作可能 |
| GLTFExporter の処理中にモードを切り替え | エクスポート完了まで「エクスポート」ボタンをローディング状態にする |

## スコープ外

- エディタ内での3Dプレビュー表示
- glTF マテリアル・テクスチャの編集
- 複数のモデルバリエーション管理
- インポートした glTF のグリッド編集（原理的に不可能）
