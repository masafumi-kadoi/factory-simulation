# 要求内容

## 概要

sim-visualizerにおけるモジュラーステーションの表示を、レイヤー切替モーダル方式に変更する。第1レイヤーではモジュラー内部のワーク移動を非表示にし、ダブルクリックで開くモーダル内に第2レイヤーとして内部の動きを表示する。

## 背景

現在のsim-visualizerでは、モジュラーステーションがデフォルトで折りたたみ状態になっており、内部ステーション間のワーク移動がモジュラーステーション上で「同じ位置から同じ位置への移動アニメーション」として表示される。これはユーザーにとって意味のない動きであり、視覚的に混乱を招く。

モジュラーの内部構造は「別レイヤー」として扱うべきであり、第1レイヤー（トップレベル）と第2レイヤー（モジュラー内部）を明確に分離することで、それぞれの粒度に適した可視化を実現する。

## 実装対象の機能

### 1. 第1レイヤーでのワーク静止表示

- モジュラーステーションにワークが入った場合、ワークはモジュラーステーション上に**静止**して表示される
- モジュラー内部でのステーション間移動（entry→processing→exitなど）では、第1レイヤー上のワーク位置は変化しない
- ワークがモジュラーから出発する時のみ、モジュラーから次ステーションへの移動アニメーションが表示される
- モジュラーに入っているワークの数が視覚的に分かるようにする（複数ワークが重なる場合はオフセット配置など）

### 2. ダブルクリックによるモーダル表示

- モジュラーステーションをダブルクリックすると、モーダルウィンドウが表示される
- モーダル内には、そのモジュラーの内部ステーション（Entry, Processing, Exit等）が配置された3Dシーンが表示される
- 内部ステーション間のワーク移動アニメーションがモーダル内で再生される
- モーダル表示中も、背景の第1レイヤーはアニメーションが継続する（両方同時に動作）
- モーダルは閉じるボタンまたはモーダル外クリックで閉じる

### 3. ネスト対応

- モジュラー内にモジュラーが配置されている場合（ネスト）、第2レイヤーのモーダル内でさらにダブルクリック → 第3レイヤーのモーダルが表示される
- レイヤーの深さに制限はない（再帰的に対応）

### 4. 既存機能との整合

- シングルクリックによるモジュラーの展開/折りたたみ機能は廃止する（ダブルクリックモーダルに置き換え）
- 再生/一時停止/シーク操作は全レイヤーで同期する（同一タイムラインを共有）
- ワーク情報モーダル（ワーククリック時）は引き続き動作する

## 受け入れ条件

### 第1レイヤーのワーク静止表示
- [ ] モジュラーに入ったワークがモジュラーステーション上で静止している
- [ ] モジュラー内部の移動（entry→processing→exit）で第1レイヤーのワーク位置が変化しない
- [ ] モジュラーからワークが出発する時に移動アニメーションが正しく表示される
- [ ] 複数ワークがモジュラー内にある場合、重ならずに表示される

### ダブルクリックモーダル
- [ ] モジュラーステーションをダブルクリックするとモーダルが表示される
- [ ] モーダル内に内部ステーションと接続が3Dで表示される
- [ ] モーダル内でワークの移動アニメーションが表示される
- [ ] モーダル表示中も第1レイヤーのアニメーションが継続する
- [ ] モーダルを閉じることができる（閉じるボタン / 外側クリック）

### ネスト
- [ ] ネストされたモジュラーをダブルクリックすると追加のモーダルが開く
- [ ] 各レイヤーが独立してアニメーションする

### 既存機能
- [ ] シングルクリックによる展開/折りたたみが廃止されている
- [ ] 再生/一時停止/シーク操作が全レイヤーで同期する
- [ ] ワーク情報モーダル（ワーククリック）が引き続き動作する

## スコープ外

以下はこのフェーズでは実装しません:

- モジュラー内部ステーションのレイアウト自動計算の改善（既存のpositionX/Y or フォースレイアウトをそのまま使用）
- モーダル内でのカメラ位置の永続化
- 第1レイヤーと第2レイヤー間のワーク移動の遷移アニメーション（エフェクト等）
- モーダルのリサイズ機能
