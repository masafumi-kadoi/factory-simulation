# 要求内容

## 概要

FactoryVisualizerのグローバルビューにおける3D表示を「設備（equipment）粒度」に変更する。
`hoge.001`, `fuga.001`, `fuga.002` のようなステーションIDがある場合、`hoge` / `fuga` 単位でまとめて1つの設備として表示する。

## 背景

現在のグローバルビューでは `stationType === 'machine'` のステーションを1つずつ個別に表示している。
実際の工場では、複数のサブステーション（`.001`, `.002` など）が1台の設備を構成することが多く、
設備単位でまとめた方が工場レイアウトの視認性が高まる。

## 実装対象の機能

### 1. 設備グループ化（equipment grouping）

- ステーションID の末尾が `.[0-9]{3}` パターンのものはベース名でグループ化する
  - 例: `conveyor.001`, `conveyor.002` → 設備 `conveyor`
  - 例: `assembler.001` → 設備 `assembler`（1台のみでも設備として扱う）
  - サフィックスなしのIDはそのまま設備名として扱う
- グローバルビューでは設備ごとに1つのシェル（半透明ボックス）を表示する
- シェルの位置 = 含まれる全マシンの重心（centroid）
- シェルのサイズ = 全マシンの座標を包含するバウンディングボックス + パディング

### 2. 設備内ステーション表示

- 設備シェルの内側に、グループに属するマシンを内部ステーション的に表示する
- 表示位置は各マシンの `positionX`, `positionY` をローカル座標として使用する
  - ローカル座標 = 設備重心からのオフセット
- マシン名ラベルも内部に表示する

### 3. 子ステーション（internal station）のローカル座標対応

- `stationType !== 'machine'` かつ `parentId` を持つステーションは、
  親マシンの位置を基準とした相対座標で描画する
  - 現在: 絶対座標として描画（バグ）
  - 修正後: 親マシングローバル座標 + ステーションローカル座標

### 4. ダブルクリックで設備ローカルビューを開く

- 設備シェルをダブルクリックすると、その設備の代表マシンのローカルビューを開く
- グループ内のいずれかのマシンをクリックしても同様に開く

## 受け入れ条件

### 設備グループ化
- [ ] `hoge.001`, `hoge.002` が存在する場合、グローバルビューに `hoge` として1つのシェルで表示される
- [ ] シェルは半透明で、内部のマシン位置が視認できる
- [ ] シェルに設備名ラベルが表示される
- [ ] サフィックスなしID（例: `conveyor`）もシェルとして表示される

### 設備内ステーション表示
- [ ] グループに属する各マシンが設備シェル内部に表示される
- [ ] マシンの表示位置はローカル座標（重心からのオフセット）で決まる

### 子ステーション座標
- [ ] `parentId` を持つ内部ステーションが親マシンの位置基準で表示される

### ダブルクリック
- [ ] 設備シェルのダブルクリックでローカルビューが開く

## スコープ外

以下はこのフェーズでは実装しません:
- 設備グループのグローバル位置をドラッグで変更する機能
- ローカルビューでのマシン位置ドラッグ編集（将来フェーズ）
- 設備グループ専用のローカルビュー画面（現行の machine local-window を流用）
